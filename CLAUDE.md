# Levela Academy

Marketing website for Levela Academy (business & creative school, partnered with Talentiv Jobs). Site copy is Indonesian.

- Stack: Next.js 16 (App Router, TypeScript) with static export, Tailwind CSS 4, Vitest.
- Content lives in typed files under `content/` (programs, talents, partners, FAQ, site info). Edit these to change prices, batches, links.
- Commands: `npm run dev` (local), `npm test`, `npm run build` (writes static site to `out/`; upload its contents to Hostinger `public_html`).
- Design spec: `docs/superpowers/specs/2026-10-23-levela-website-design.md`. Brand: `docs/brand/`.
- Remote: https://github.com/Fdhlu-Rhmn/Levela.git (branch `main`).
- Scope: work only inside this folder. The parent `C:\xampp\htdocs` holds unrelated projects; ignore it.
