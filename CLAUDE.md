# Levela Academy

Static landing page for Levela Academy (business & creative school, linked to Talentiv Jobs). Content language: Indonesian.

- Plain HTML/CSS/JS, no build step, no dependencies: `index.html`, `style.css`, `app.js`, `assets/`.
- Run: `python -m http.server 8765` in this folder, or XAMPP Apache at `http://localhost/levela/`.
- Remote: https://github.com/Fdhlu-Rhmn/Levela.git (branch `main`).
- Scope: work only inside this folder. The parent `C:\xampp\htdocs` holds unrelated projects and its own git repo; ignore it.
