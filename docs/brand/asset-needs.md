# Aset yang Dibutuhkan

Semua file di bawah ini saat ini **placeholder**: kotak gradien oranye bertuliskan nama file. Ganti dengan aset asli. Jangan memakai foto stok atau sertifikat buatan sebagai pengganti dokumentasi asli.

Cara mengganti: simpan file asli lalu jalankan
```
node scripts/to-webp.mjs <file-asli> public/images/<nama-file> <lebar>
```
